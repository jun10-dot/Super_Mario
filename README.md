# Super_Mario

[게임 실행](https://github.com/jun10-dot/Super_Mario/releases/latest)

[전체 플레이 영상 (YouTube)](https://youtu.be/VcpRu3NX5JY)

## 📍 프로젝트 소개
- 고전 2D 슈퍼마리오 게임을 모티브로 Unity로 제작한 게임 클론 프로젝트

## 🔎 프로젝트 정보
- 프로젝트 기간 : 2025년 08월 ~ 09월 (3주 반)
- 개발 인원 : 1명

## 🦾 기술 스택
- 언어 : C#
- 엔진 : Unity
- 개발 환경 : Visual Studio 2022

## ⌨️ 조작법
- 이동 및 점프 : (W,A,S,D) 혹은 화살표 키, SpaceBar 키
- 가속 : 키보드 Z 키 + 이동 키
- 기믹 요소: S - 지하 이동, D - 지하 탈출

## 🎯 주요 기능
- Tilemap & Grid 기반 맵 제작
- 랜덤 블록(버섯, 코인), 적, 다양한 기믹 요소(지하, 엔딩) 구현
- 물리 기반 플레이어 이동(걷기, 달리기, 점프 감속) 및 변신 시스템

## 🛠️ 향후 계획
- 플레이어 상태 전환을 FSM 패턴으로 구조 재설계
- 점수 및 코인 UI 추가
- 플레이어와 상호작용하는 오브젝트들은 추상 인터페이스로 구조 재조정
- 효과음 및 배경 음악
- 레벨 시스템 도입
